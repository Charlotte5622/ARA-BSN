# ARA-BSN: Adaptive Region-aware Blind-spot Network for Self-supervised Real Image Denoising

## 📖 Overview

ARA-BSN is a state-of-the-art self-supervised real image denoising network that leverages adaptive region-aware processing and blind-spot network architecture. The model introduces innovative techniques including asymmetric pixel downsampling, multi-scale processing, and Random Replacement Refinement (R3) to achieve superior denoising performance on real-world noisy images.

## 🚀 Quick Start

### Prerequisites

- Python 3.9+
- PyTorch 2.x (tested with 2.3.1 + CUDA 11.8)
- CUDA (required)
- OpenCV, NumPy, scikit-image
- PyYAML, SciPy, h5py, TensorBoard

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Charlotte5622/ARA-BSN.git
cd ARA-BSN
```

2. Install dependencies:
```bash
pip install torch torchvision opencv-python numpy scikit-image pyyaml scipy h5py tensorboard
```

3. Create dataset directory:
```bash
mkdir dataset
```

### Dataset Preparation

ARA-BSN supports three major denoising datasets:

- **SIDD**: Smartphone Image Denoising Dataset
- **DND**: Darmstadt Noise Dataset  
- **NIND**: Natural Image Noise Dataset

#### Download and Setup

1. Download datasets from official sources:
   - [SIDD](https://www.eecs.yorku.ca/~kamel/sidd/)
   - [DND](https://noise.visinf.tu-darmstadt.de/)
   - [NIND](https://commons.wikimedia.org/wiki/Natural_Image_Noise_Dataset)

2. Organize directory structure:
```
ARA-BSN/
├── dataset/
│   ├── SIDD/
│   │   ├── SIDD_Medium_Srgb/
│   │   ├── SIDD_Validation/
│   │   │   ├── ValidationGtBlocksSrgb.mat
│   │   │   └── ValidationNoisyBlocksSrgb.mat
│   │   └── SIDD_benchmark/
│   │       └── BenchmarkNoisyBlocksSrgb.mat
│   ├── DND/
│   │   └── images_srgb/
│   └── prep/                 # generated by prep.py

```

3. Prepare datasets:
```bash
# SIDD dataset
python prep.py -d SIDD

# DND dataset  
python prep.py -d DND

# SIDD benchmark
python prep.py -d SIDD_benchmark -s 256 -o 0

# NIND dataset
python prep.py -d NIND
```

## 🔧 Training

### Configuration

Training configurations are stored in `conf/` directory:
- `ARA_SIDD.yaml`: SIDD dataset configuration
- `ARA_DND.yaml`: DND dataset configuration  

### Start Training

```bash
# Train on SIDD dataset
python train.py -c ARA_SIDD -s session_name

# Train with specific GPU
python train.py -c ARA_SIDD -s session_name -g 0

# Resume training
python train.py -c ARA_SIDD -s session_name -r

# Train without auto-shutdown
python train.py -c ARA_SIDD -s session_name --no-shutdown
```

**Note**: training shuts down the machine by default (`shutdown -h +1` on Linux, `shutdown /s` on Windows). Pass `--no-shutdown` to disable it.

## 🧪 Testing

### Model Evaluation

```bash
# Test a specific epoch
python test.py -c ARA_SIDD -s session_name -e 30

# Test the latest epoch of the session
python test.py -c ARA_SIDD -s session_name -e -1

# Test with a pretrained checkpoint
python test.py -c ARA_SIDD --pretrained /path/to/checkpoint/ARA-BSN_SIDD.pth

# Test on a single image (square images only)
python test.py -c ARA_SIDD --test_img path/to/image.png

# Test on directory
python test.py -c ARA_SIDD --test_dir path/to/images/
```
